# MachiKania-BME280

温湿度､気圧センサーBME280をMachiKaniaでI<sup>2</sup>Cで通信で使うためのクラスライブラリです。

- BME280I2.BAS : I<sup>2</sip>を使用するクラスライブラリ
- BME280TI.BAS : クラスライブラリの使用例

# インストール

ライブラリファイル（`BME280I2.BAS`）はそれを利用するプログラムと同じフォルダ､あるいは`/LIB/BME280I2`に保存してください。

# クラスを使用するための設定

このライブラリを使用スにはBME280のSCLおよびSDA端子を接続するRaspberry Pi Picoのピン番号を`MACHIKAP.INI`で指定する必要があります。
たとえば､SDAをGP8､SCLをGP9に接続する場合は次のように設定します。

```INI
I2CSDA=8
I2CSCL=9
```

# BME280のモード設定

このライブラリでは`INIT`メソッでBME280を次のモードで初期化します。

|レジスタ|レジスタ名|設定値|設定内容|
|:----:|----|:----:|----|
|$F2|ctrl_hum|$01|湿度のオーバーサンプリング×1|
|$F4|ctrl_meas|$27|気圧と温度のオーバーサンプリング×1､ノーマルモード|
|$F5|config|$20|測定待機時間62.5ms､フィルタオフ|

# メソッド､フィールド一覧

このライブラリでは次のパブリックメソッド､フィールドを使用できます。

## パブリックメソッド

下記のパブリックメソッドを使用できます。

| メソッド | 引数                   | 機能|
|:----:|----|----|
| INIT | I<sup>2</sup>Cアドレス | BME280の初期化と補正データの取得|
| GETDATA  | なし | 温度､湿度､気圧の取得。それぞれの値は次のフィールドに保存 |

## パブリックフィールド

温度､湿度､気圧データを取得した後､それぞれの値はパブリックフィールドに格納されます。

|フィールド|値|
|------|----|
|TEMP#|℃単位の温度|
|HUMI#|％単位の湿度|
|PRESS#|hPa単位の気圧|

# 使用例

このクラスの使用例を示します。
クラスの使用指定し､`INIT`メソッドで初期化し､`GETDATA`メソッドで温度､湿度､気圧を取得します。取得した温度､湿度､気圧はパブリックフィールドに保存されています。

``` BASIC
USECLASS BME280I2
A=$76
BME280I2::INIT(A)
BME280I2::GETDATA()

PRINT "Temperature:";BME280I2::TEMP#
PRINT "Humidity   :";BME280I2::HUMI#
PRINT "Presssure  :";BME280I2::PRESS#

END
```
